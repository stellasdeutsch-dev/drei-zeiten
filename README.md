# Präsens · Perfekt · Präteritum

Разбор трёх немецких времён (уровень A2) в коллажном формате северного
дневника + витрина платформы **Stellas Deutsch** (A0 → C1).

**Живая страница:** https://stellasdeutsch-dev.github.io/drei-zeiten/

## Что внутри

- Тема объяснена через приём «три брата»: Präsens, Perfekt, Präteritum как
  персонажи с характерами.
- Интерактивная шкала «Разговор ↔ Текст».
- Сводная таблица на тетрадной странице, карточки-ошибки с переворотом.
- Тест на 6 вопросов с анимированным прогресс-баром и кольцом результата.
- Блок болей на реальных ответах подписчиков + диаграмма их разбора.
- Витрина платформы: настоящие видео продукта и скриншоты, реальные отзывы.

## Стек

Чистые HTML/CSS/JS без зависимостей и сборки. Mobile-first.
Шрифты — Google Fonts (Cormorant, Marck Script, Golos Text, Playfair Display).
Орнаменты и зерно бумаги — сгенерированные SVG.

## Правки

- Ссылки на Telegram и Instagram — в `index.html` (поиск по `t.me`).
- Цены и состав платформы — секции `#price` и `#platform`.
- Медиа лежит в `media/` (`video/` — mp4, `img/` — скриншоты и орнаменты).
